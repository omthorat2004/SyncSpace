╚════════════════════════════════════════════════════════════════════════════════╝

CREATE CONTENT FLOW:
─────────────────────

User Input (React Form)
        ↓
Form Validation (Frontend)
        ↓
Redux Action: createContent()
        ↓
API Call: POST /api/v1/spaces/{id}/contents
        ↓
Router: create_content()
        ↓
Service: create_content()
        ├─ Validate inputs
        ├─ Check authorization
        └─ Call DAO
        ↓
DAO: create_content()
        ├─ Insert into database
        └─ Return created content
        ↓
Service: Invalidate cache
        ├─ Delete space:id:contents
        ├─ Delete space:id:contents:type:*
        └─ Delete space:id:stats
        ↓
Response: CreateContentResponse
        ↓
Redux: Update state
        ├─ Add content to list
        ├─ Close modal
        └─ Clear error
        ↓
UI Update: Display new content


GET CONTENTS FLOW (WITH CACHING):
──────────────────────────────────

User navigates to space
        ↓
Redux Action: fetchContents()
        ↓
API Call: GET /api/v1/spaces/{id}/contents
        ↓
Router: get_contents()
        ↓
Service: get_space_contents()
        ├─ Check cache
        │   ├─ Cache HIT → Return cached data
        │   └─ Cache MISS → Continue
        ├─ Check authorization
        └─ Call DAO
        ↓
DAO: get_contents_by_space()
        ├─ Query database
        └─ Return contents
        ↓
Service: Cache results
        ├─ Store in Redis
        └─ Set TTL (1 hour)
        ↓
Response: GetContentsResponse
        ↓
Redux: Update state
        ├─ Set contents list
        └─ Clear error
        ↓
UI Update: Display contents


╔════════════════════════════════════════════════════════════════════════════════╗
║                          SECURITY ARCHITECTURE                                ║
╚════════════════════════════════════════════════════════════════════════════════╝

Authentication:
  JWT Token → Verify Signature → Extract User ID → Attach to Request

Authorization:
  User ID → Check Ownership → Verify Space Owner → Allow/Deny Operation

Input Validation:
  Frontend Validation → Backend Validation → Database Constraints

Error Handling:
  Custom Exceptions → HTTP Status Codes → Generic Error Messages
